# Design_Agents_app
The Intelligent Multi-Agent Adaptive Learning System is an AI-based tutoring platform that personalizes education using multiple cooperating intelligent agents. The system analyzes student interactions such as answers, response time, hints used, and topic difficulty to estimate the student’s knowledge level using probabilistic reasoning. Based on this model, the agents decide the next learning action, adjust difficulty, and plan an optimal learning path.
The system can generate different types of assessments including MCQ, True/False, short answers, and essay questions, while also recommending educational videos and learning resources that target the student’s weak concepts. Additional features include personalized study plans, adaptive quizzes, automatic feedback and explanations, progress analytics dashboards, concept prerequisite tracking. Reinforcement learning continuously improves teaching strategies, allowing the platform to adapt and optimize the learning experience over time.
