## How It Works - MCQ Example

### Scenario: Student answers a Multiple Choice Question

**Question Generated by LLM**:
```json
{
  "question": "Where do light reactions occur?",
  "options": [
    "Stroma of chloroplast",
    "Thylakoid membranes",  ← This is correct
    "Mitochondrial matrix",
    "Ribosome"
  ],
  "correct_answer": "Thylakoid membranes",  ← Hidden from user
  "key_points": ["light reactions", "thylakoid", "photosynthesis"]
}
```

**Student Answers**: "Thylakoid membranes"

**Backend Processing**:
1. Receive answer
2. Compare: `"Thylakoid membranes"` === `"Thylakoid membranes"` ✅
3. **0ms elapsed** (no LLM call!)
4. Return: CORRECT
5. Run BKT/IRT
6. Ask LLM: "What should we do next?" (ONLY LLM call)
7. Response: "SHOW_NEXT_QUESTION"

**Frontend Shows**: ✅ CORRECT! Good work!

## One More Thing: Where is LLM Actually Used?

**LLM is ONLY called for**:
1. ✅ Generating new questions (with hidden correct answer)
2. ✅ Deciding what to do next (after grading)

**LLM is NOT called for**:
1. ❌ Grading answers (instant comparison)
2. ❌ Showing feedback (all static)
3. ❌ Storing student data (just JSON)
